# Team Standards

- Minimize context usage wherever possible.
- Provide an answer only when you can verify the accuracy of your sources; otherwise, clearly state: "Insufficient information."
- Use only approved libraries, specifically those that are open source or provided by IBM.
- Keep code documentation to the minimum necessary.
- Always use the most suitable mode for the job you have to do.
- Always use subagents when it makes sense to speed up the job you have to do.
